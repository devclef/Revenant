# Ceremony assets

Every asset file under `src/components/ceremony/assets/` is listed here, one row per
file (R15.2). An asset is an image, texture, font file, icon or sound the ceremony
adds. An asset with no entry here fails the Property 23 test.

Rules for every entry:

- The licence is `original` (made in this repository) or `CC0`. Nothing else is
  added (R15.1).
- Each asset file is at most 150 kB, and the total of all asset bytes stays within
  the R13.5 budget (150 kB total, 40 kB before first paint).
- Prefer assets that are code: CSS gradients, inline SVG paths and procedural
  patterns. Add a file only when a texture cannot be drawn in code (R15.4).
- The existing fonts (EB Garamond, Inter, both OFL, in `src/app/fonts`) are reused.
  No font is added (R15.3).
- No asset is generated by an AI image tool unless the owner approves it and its
  licence terms are recorded in the row (R15.5).
